# Task Management Dashboard

A full-stack task management web application built as part of the internship assignment.

## Tech Stack
- **Database:** Supabase (PostgreSQL)
- **Backend:** Python Flask (with Flask-CORS & Gmail SMTP for email notifications)
- **Frontend:** Next.js (TypeScript & Tailwind CSS)
- **Authentication:** Supabase Auth (Google OAuth / Email)

## Features
- User Authentication & Role management.
- Create and assign tasks to other users.
- Automated Gmail notifications on task creation and completion.
- Modern responsive UI with Tailwind CSS.
